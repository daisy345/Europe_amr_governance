# Antimicrobial use, resistance and AMR-associated death figures

This repository contains processed inputs, available code and figure outputs for five sets of analyses in Europe: [Figure 1](Figure_1/) presents maps of human and animal antimicrobial use (AMU) and antimicrobial resistance (AMR) scores; [Figure 2](Figure_2/) presents temporal trends in AMU, AMR scores and AMR-associated deaths; [Figure 3](Figure_3/) presents difference-in-differences event studies; [Figure 4](Figure_4/) presents historical and projected human AMR trajectories under SSP and policy scenarios; and [Figure 5](Figure_5/) presents mortality-model validation and projections. Each directory contains its own README with reproduction instructions. Figure 2 includes R scripts for redrawing results exported from Joinpoint Regression Software, but not the complete workflow needed to refit its models. The inputs are processed data and do not necessarily include upstream raw data or every earlier analysis step.
